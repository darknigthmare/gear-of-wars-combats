## Vérification et reprise technique

Le [rapport de validation V7](VALIDATION_V7.json) détaille les 74 PNG contrôlés, les six journaux de génération, les 34 liens de costumes et la vérification statique de la galerie. Il ne signale aucune erreur technique.

Les **8 tests d’inventaire ont réussi** au contrôle de clôture : 4 V6 et 4 V7. Les catalogues versionnés sont chargés dans l’ordre numérique ; les identités sont fusionnées par ID sans ajouter de combattant au roster du moteur. Le mapping de costumes vérifie l’asset actif, le personnage parent, l’empreinte SHA-256, le journal déjà associé et les preuves complémentaires, sans copier de PNG.

```bash
python -m unittest discover -s tests -p 'test_inventory_v*.py' -v
python src/consolidate_inventory.py
python src/validate_data.py
node prototype/build.mjs
node prototype/tests.cjs
```

Les deux commandes Node reconstruisent et vérifient le prototype ; le présent audit de documentation n’en déclare aucune nouvelle fonctionnalité. Les limites de validation navigateur et manette restent celles décrites dans le [README](../../README.md).

La contribution continue dans la [PR #1](https://github.com/darknigthmare/gear-of-wars-combats/pull/1), branche `codex/gears-combats-corpus-v6-20261120`. Les commits de cette PR constituent la référence de publication.
