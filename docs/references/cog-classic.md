# Références visuelles — COG classiques

Vérification du 19 novembre 2026. Ce registre couvre Clayton Carmine, Samantha Byrne, Dizzy Wallin, Tai Kaliso et Victor Hoffman. Les fichiers source ont été inspectés visuellement. Les images externes restent des références de travail ; aucune copie n’est incorporée au dépôt.

**État de fidélité : aucune conformité 1:1 globale n’est revendiquée.** Les recadrages, concepts et versions incertaines sont explicités. Une image en pied générée à partir d’un portrait ne prouve pas les détails hors champ.

Le registre structuré correspondant est [cog-classic.json](../../production/history/reprise_2026-11-19/production/references/cog-classic.json). Les chemins temporaires indiqués peuvent disparaître ; les URL identifient les sources.
