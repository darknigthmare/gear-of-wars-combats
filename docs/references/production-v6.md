# Références de production V6

Vérifiées le 20 novembre 2026. Ce dossier accompagne le [catalogue JSON](../../data/production_catalog_v6.json) et le [listing lisible](../production/LISTING_V6.md).

## Utilisation des sources

Les annonces de l’éditeur attestent l’identité des contenus et leur édition. Les portfolios cités sont ceux d’artistes ayant travaillé sur les productions; les concepts y restent distincts des modèles finaux. Les guides officiels documentent les jeux sources, sans fournir la frame data de cette adaptation de combat 2D.

Les références secondaires déjà présentes dans la fiche de Matriarch sont conservées par fusion; les deux portfolios ajoutés apportent sa preuve visuelle primaire. La fidélité 1:1 reste à contrôler image par image.

## Contrôles d’édition

Le rendu Black Steel Anthony documente une variante Gears 5 et ne doit pas remplir l’apparence de campagne 2006. Les portfolios Hana et tenues d’introduction Hivebusters contiennent des concepts de production: vérifier les décisions conservées dans le jeu. Les variantes de récompenses de Gears 5 sont confirmées par leur nom dans les annonces; leurs découpes et palettes nécessitent toujours une inspection visuelle.
