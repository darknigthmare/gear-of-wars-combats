# Sources et prompts — passe V11

Les prompts et réserves de chaque image sont conservés dans les journaux de `data/generation_v11`. Les refus et les recherches sans génération sont distingués. Les références téléchargées pour la recherche restent hors des assets publiés ; seuls les PNG générés sélectionnés sont intégrés.

Les sources primaires, les concepts de production, les captures miroirs, les ports communautaires et les figurines sous licence sont identifiés dans les journaux. Un concept ou une version différente ne valide pas automatiquement le modèle final de l’édition cible.
