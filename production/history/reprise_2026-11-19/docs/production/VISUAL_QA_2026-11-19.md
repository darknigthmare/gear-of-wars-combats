## Vérifications techniques communes

- Six fichiers PNG en mode **RGBA**, avec un canal alpha réel couvrant les valeurs 0 à 255. Le fond n'est pas un rectangle noir peint.
- Environ 56 à 65 % des pixels sont exactement transparents, selon l'image.
- Le corps principal a un alpha surtout compris entre 252 et 253, soit une quasi-opacité. Les faibles valeurs d'alpha sur le contour incluent de petits pixels résiduels ; le canal ne constitue pas un masque binaire parfaitement nettoyé.
- Tous les personnages montrent la tête, les mains et les deux pieds. Aucun membre principal manifestement coupé n'a été observé.
- Les marges ci-dessous utilisent **alpha ≥ 128** afin de distinguer le personnage des pixels presque transparents. Un recadrage automatique basé sur `alpha > 0` serait perturbé par les résidus de bord.
